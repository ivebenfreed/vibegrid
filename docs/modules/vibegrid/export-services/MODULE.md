# Export Services

> How does data leave the grid as CSV, PDF, or ZIP?

Client-side CSV export with type-aware formatting, PDF generation via Cloudflare Browser Rendering, and ZIP packaging for bulk document exports. Stored in R2 with org-scoped keys.
